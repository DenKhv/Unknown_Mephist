[[gp_timer_slave]]
== GP_Timer_Slave peripheral block (GP_TIMERS_Slave)

The <<figure-timer_slave>> figure shows the structural diagram of the GP_Timer_Slave peripheral block.


[#figure-timer_slave]
.Structural diagram of the GP_Timer_Slave
image::GP_TIMER.png[scaledwidth=14cm]


The input 64-bit value SYNC_VALUE in Gray code from the GP_Timer_Master block is sent to the input of the GP_Timer_Slave block. This value is converted back to a binary value and written to the CNTR register, which consists of two 32-bit parts CNTR_H and CNTR_L. These parts can be programm read or rewritten to the SAVED_CNTR register, which also consists of two parts. It is used when it is necessary to read the full 64-bit value of the time scale. In this case, reading is performed in parts of 32 bits. Therefore, with two consecutive readings, the value of the CNTR register may change and the read parts will not correspond to each other.

Also, the GP_Timer_Slave block provides for the generation of events when a specified value written to the CMPR register is exceeded. The CNTR register value is compared with the CMPR value. When the CNTR register value exceeds the CMPR register value, the corresponding bit in the IRQR register is set.

If the cyclic comparator operation mode is configured, then after setting the bit in the IRQR register, the CMP register is incremented by the value written to the INC register and operation continues. In the single comparator operation mode, after the event is generated, further comparisons are stopped. All bits of the IRQR register are combined using the "OR" function and can be used as an interrupt request.

There are two event generation schemes. Each scheme contains identical CMP and INC registers, distinguished by a postfix (_0 or _1). The CMP and INC registers consist of two 32-bit parts, accessible for reading and writing.

==== ENABLE register

The ENABLE register controls the operation of the comparators. If the comparator is enabled, then when the value of the CNTR register exceeds the threshold value written in the CMPR register, the corresponding bit of the IRQR register will be set.

The <<tbl_rf_ENABLE_GP_Timer_Slave>> contains a description of the fields of the ENABLE register.

.Description of the ENABLE register fields
[#tbl_rf_ENABLE_GP_Timer_Slave,cols="4,15,6,6,27",options="header"]

| 1        | EN_CMP_1       | RW           | 0x0                 |  comparator CMP_1 control: +
                                                                          0 - comparator CMP_1 disable; +
                                                                          1 - comparator CMP_1 enable;  +
| 0        | EN_CMP_0       | RW           | 0x0                 |  comparator CMP_0 control: +
                                                                          0 - comparator CMP_0 disable; +

==== ENABLE_SET register

When writing to the ENABLE_SET register, in those bits where there was a "1", the corresponding bit of the ENABLE register will be set, in those bits where there was a "0", the value of the ENABLE register will not change.

==== ENABLE_RST register

When writing to the ENABLE_RST register, in those bits where there was a "1", the corresponding bit of the ENABLE register will be reset, in those bits where there was a "0", the value of the ENABLE register will not change.


==== CYCLIC register

The CYCLIC register controls the comparator operating mode. There are 2 modes: cyclic and single. In the single mode, after the event occurs when the value of the CNTR register exceeds the threshold value written to the CMPR register stops the comparator and automatically resets the corresponding bit in the ENABLE register. In the cyclic mode, after the event occurs when the value of the CNTR register exceeds the threshold value written to the CMPR register increments the CMPR register and the comparator continues to operate. Stopping occurs only after a software reset of the ENABLE register or a mode change.

The <<tbl_rf_CYCLIC_GP_Timer_Slave>> contains a description of the fields of the CYCLIC register.
