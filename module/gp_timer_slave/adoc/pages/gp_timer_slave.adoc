== Перефирийный блок GP_Timer_Slave (GP_TIMERS_Slave)

На рисунке <<figure-timer_slave>> представлена структурная схема перефирийного блока GP_Timer_Slave.



[#figure-timer_slave]
.Структурная схема перефирийного блока GP_Timer_Slave
image::GP_TIMER.png[scaledwidth=14cm]

Входное 64-х разрядное значение SYNC_VALUE в коде Грея от блока GP_Timer_Master поступает на вход блока GP_Timer_Slave. Данное значение преобразуется обратно в двоичное значение и записываетя в регситр CNTR, состоящий из двух 32-х битных частей CNTR_H и CNTR_L. Данные части могут быть считаны программно или переписаны в регистр SAVED_CNTR, который так же состоит из двух частей. Данная запись используется при необходимости считать полное 64-х разрядное значение шкалы времени. При этом чтение осуществляется частями по 32 разряда. Поэтому при двух последовательных чтениях, значение регистра CNTR может поменяться и считанные части не будут соответствовать друг другу. 

Так же в блоке GP_Timer_Slave предусмотрено формирование событий при превышении заданного значения, записанного в регистр CMPR. Значение регистра CNTR сравнивается с значением CMPR. При превышении значения регистра CNTR над значением регистра CMPR устанавливается соответствующий бит в регистре IRQR. 

Если настроен циклический режим работы компаратора, то после установки бита в регистре IRQR происходит инкрементирование регистра CMP на значение, записанное в регистр INC и работа продолжается дальше. При одиночном режиме работы компаратора после формирвоания события дальнейшие сравнения прекращаются. Все биты регистра IRQR объединяются по функции "ИЛИ" и могут быть использованы в качестве запроса на прерывание.

Предусмотрено две схемы формирования событий. Каждая схема содержит одинаковые регистры CMP и INC, отличающиеся постфиксом (_0 или _1). Регистры CMP и INC состоят из двух 32-х битных частей, доступных по чтению и записи.

==== Регистр ENABLE_SET 

При записи в регистр ENABLE_SET в тех разрядах где была "1" произойдет установка соответствующего бита регистра ENABLE, в тех разрядах где был "0" значение регистра ENABLE не изменится.

==== Регистр ENABLE_RST 

При записи в регистр ENABLE_RST в тех разрядах где была "1" произойдет сброс соответствующего бита регистра ENABLE, в тех разрядах где был "0" значение регистра ENABLE не изменится.


==== Регистр CYCLIC 

Регистр CYCLIC управляет режимом работы компараторов. Существует 2 режима: цикличческий и одиночный. При одиночном режиме после появления события при привышении значения порога, записанного в регистр CMPR, значением регистра CNTR происходит остановка компаратора и автоматический сброс соответствующего бита в регистре ENABLE. При циклическом режиме после появления события при привышении значения порога, записанного в регистр CMPR, значением регистра CNTR происходит инкрементирование регистра CMPR и компаратор продолжает работать. Остановка происходит только после программного сброса регистра ENABLE или смене режима.

==== Регистр IRQR 

Регистр IRQR содержит информацию о поступивших событиях от компараторов. При возникновения события превышения порога происходит установка соответствующего разряда регистра IRQR. Выход регистра может быть использован как запрос на прерывание. Сброс осуществляется программно.
